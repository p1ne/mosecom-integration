# Руководство по установке интеграции Мосэкомониторинг

## Метод 1: Ручная установка

1. **Скачайте файлы интеграции**
   - Скачайте всю директорию `custom_components/mosecom`
   - Убедитесь, что у вас есть все необходимые файлы:
     - `__init__.py`
     - `manifest.json`
     - `config_flow.py`
     - `const.py`
     - `coordinator.py`
     - `sensor.py`
     - `strings.json`
     - `services.yaml`
     - `hacs.json`

2. **Скопируйте файлы в Home Assistant**
   - Получите доступ к файлам Home Assistant (через Samba, SSH или дополнение File Editor)
   - Перейдите в директорию `custom_components`
   - Если её нет, создайте: `mkdir custom_components`
   - Скопируйте директорию `mosecom` в `custom_components`

3. **Перезапустите Home Assistant**
   - Перейдите в **Настройки** → **Система** → **Перезапустить**
   - Или перезапустите через командную строку: `hassio.host.restart`

4. **Добавьте интеграцию**
   - Перейдите в **Настройки** → **Устройства и службы**
   - Нажмите **Добавить интеграцию**
   - Найдите "Moscow Air Quality Monitoring"
   - Нажмите на неё
   - Выберите станцию мониторинга из списка
   - При желании укажите пользовательское имя для устройства
   - Нажмите **Отправить**

## Метод 2: Установка через HACS (Home Assistant Community Store)

1. **Установите HACS** (если ещё не установлен)
   - Следуйте официальному руководству по установке HACS: https://hacs.xyz/docs/setup/start

2. **Добавьте эту интеграцию в HACS**
   - Откройте HACS в Home Assistant
   - Перейдите в **Настройки** → **Пользовательские репозитории**
   - Нажмите **Добавить**
   - Введите URL репозитория: `https://github.com/p1ne/mosecom`
   - Выберите категорию: **Интеграция**
   - Нажмите **Добавить**

3. **Установите интеграцию**
   - Перейдите в **HACS** → **Интеграции**
   - Найдите "Moscow Air Quality Monitoring"
   - Нажмите **Скачать**
   - Нажмите **Скачать** ещё раз для подтверждения
   - Дождитесь завершения установки

4. **Перезапустите Home Assistant**
   - Нажмите **Перезапустить** в диалоге HACS
   - Или перезапустите вручную: **Настройки** → **Система** → **Перезапустить**

5. **Добавьте интеграцию**
   - Следуйте тем же шагам, что и в Методе 1, шаг 4

## Метод 3: Установка через терминал/SSH

1. **Получите доступ к Home Assistant через SSH**
   ```bash
   ssh homeassistant@your-home-assistant-ip
   ```

2. **Перейдите в директорию custom_components**
   ```bash
   cd /home/homeassistant/.homeassistant/custom_components
   ```

3. **Клонируйте или скачайте интеграцию**
   ```bash
   # Если у вас установлен git
   git clone https://github.com/p1ne/mosecom.git mosecom
   
   # Или скачайте и распакуйте вручную
   wget https://github.com/p1ne/mosecom/archive/main.zip
   unzip main.zip
   mv mosecom-main mosecom
   ```

4. **Установите правильные права доступа**
   ```bash
   chown -R homeassistant:homeassistant mosecom
   chmod -R 755 mosecom
   ```

5. **Перезапустите Home Assistant**
   ```bash
   hassio.host.restart
   ```

6. **Добавьте интеграцию** (так же, как в Методе 1, шаг 4)

## Выбор станции

Для выбора станции мониторинга:

1. Посетите https://mosecom.mos.ru/
2. Найдите нужную станцию мониторинга
3. Скопируйте URL из адресной строки браузера
4. Используйте этот URL при настройке интеграции

Примеры URL:
- https://mosecom.mos.ru/m1-6-moskvorechye-saburovo/
- https://mosecom.mos.ru/m1-1-bibirevo/
- https://mosecom.mos.ru/m1-2-losinyj-ostrov/

## Проверка

После установки проверьте, что всё работает:

1. **Проверьте интеграцию**
   - Перейдите в **Настройки** → **Устройства и службы**
   - Вы должны увидеть "Moscow Air Quality Monitoring" в списке
   - Нажмите на неё, чтобы увидеть настроенные устройства

2. **Проверьте сенсоры**
   - Перейдите в **Настройки** → **Объекты**
   - Найдите сенсоры, начинающиеся с "sensor.{имя_местоположения}_, например, "sensor.moskvorechye_saburovo_"
   - Вы должны увидеть сенсоры для каждого типа газа с единицами измерения мг/м³ и % ПДК

3. **Проверьте устройство**
   - Перейдите в **Настройки** → **Устройства**
   - Вы должны увидеть устройство с именем "Mosecom {Имя вашего местоположения}"
   - Нажмите на него, чтобы увидеть все связанные сенсоры

## Устранение неполадок

### Интеграция не отображается

1. Проверьте, что все файлы находятся в правильном месте:
   ```
   /home/homeassistant/.homeassistant/custom_components/mosecom/
   ```

2. Проверьте логи Home Assistant:
   - Перейдите в **Настройки** → **Система** → **Журналы**
   - Найдите ошибки, связанные с "mosecom"

3. Убедитесь, что вы перезапустили Home Assistant после установки

### Сенсоры недоступны

1. Проверьте, что URL станции мониторинга правильный
2. Проверьте подключение к интернету
3. Убедитесь, что веб-сайт станции мониторинга доступен
4. Посмотрите логи интеграции для конкретных сообщений об ошибках

### Ошибки прав доступа

1. Убедитесь, что файлы имеют правильные права доступа:
   ```bash
   chown -R homeassistant:homeassistant /home/homeassistant/.homeassistant/custom_components/mosecom
   chmod -R 755 /home/homeassistant/.homeassistant/custom_components/mosecom
   ```

### Ошибки импорта

1. Убедитесь, что все необходимые файлы присутствуют
2. Проверьте, что зависимости Python удовлетворены (для этой интеграции не требуются)
3. Убедитесь, что вы используете совместимую версию Home Assistant (2023.1.0 или позже)

## Обновление интеграции

### Ручное обновление

1. Скачайте последнюю версию интеграции
2. Замените файлы в `custom_components/mosecom`
3. Перезапустите Home Assistant

### Обновление через HACS

1. Откройте HACS
2. Перейдите в **Интеграции**
3. Найдите "Moscow Air Quality Monitoring"
4. Нажмите **Обновить**
5. Перезапустите Home Assistant при запросе

## Удаление

1. **Удалите интеграцию**
   - Перейдите в **Настройки** → **Устройства и службы**
   - Найдите "Moscow Air Quality Monitoring"
   - Нажмите на неё
   - Нажмите **Удалить**
   - Подтвердите удаление

2. **Удалите файлы**
   - Удалите директорию `custom_components/mosecom`
   - Перезапустите Home Assistant
