# Интеграция Мосэкомониторинг для Home Assistant

Интеграция позволяет мониторить качество воздуха в Москве в реальном времени, используя данные с официального сайта Мосэкомониторинг (mosecom.mos.ru).

## Особенности

- Автоматическое обнаружение типов газов для каждой станции
- Динамическое создание сенсоров для доступных газов
- Поддержка всех станций мониторинга Москвы
- Автоматическое обновление данных каждые 15 минут
- Удобный интерфейс выбора станции с отображением района и адреса
- Поддержка пользовательских имен для устройств
- Совместимость с HACS (Home Assistant Community Store)

## Установка

### Через HACS (рекомендуется)

1. Откройте HACS в вашем Home Assistant
2. Перейдите в "Интеграции"
3. Нажмите на три точки в правом верхнем углу и выберите "Пользовательские репозитории"
4. Добавьте `https://github.com/p1ne/mosecom` как репозиторий типа "Интеграция"
5. Найдите "Moscow Air Quality Monitoring" и установите его
6. Перезапустите Home Assistant

### Вручную

1. Скопируйте папку `custom_components/mosecom` в директорию `custom_components` вашего Home Assistant
2. Перезапустите Home Assistant
3. Перейдите в Настройки → Устройства и службы → Добавить интеграцию
4. Найдите "Moscow Air Quality Monitoring" и следуйте инструкциям настройки

## Настройка

1. Перейдите в Настройки → Устройства и службы → Добавить интеграцию
2. Найдите "Moscow Air Quality Monitoring"
3. Выберите станцию мониторинга из списка
4. При желании укажите пользовательское имя для устройства
5. Нажмите "Отправить"

## Сенсоры

Для каждой станции создаются сенсоры для всех доступных типов газов:
- Сенсоры в мг/м³ (миллиграмм на кубический метр)
- Сенсоры в % ПДК (процент от предельно допустимой концентрации)

Имена сенсоров формируются по шаблону:
- `sensor.[имя_устройства]_[тип_газа]_mg_m3`
- `sensor.[имя_устройства]_[тип_газа]_pdk`

## Поддерживаемые типы газов

- CO (Оксид углерода)
- NO2 (Диоксид азота)
- CH4 (Метан)
- PM10 (Взвешенные частицы PM10)
- NO (Оксид азота)
- H2S (Сероводород)
- C6H5OH (Фенол)

## Устранение неполадок

### Сенсоры недоступны
- Проверьте подключение к интернету
- Убедитесь, что URL станции доступен в браузере
- Проверьте логи Home Assistant на наличие ошибок

### Нет данных
- Некоторые станции могут не передавать данные в определенное время
- Проверьте доступность данных на официальном сайте
