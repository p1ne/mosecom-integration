# Руководство по настройке пользовательского интерфейса

Это руководство объясняет, как настроить интеграцию мониторинга качества воздуха Москвы с помощью веб-интерфейса Home Assistant.

## Обзор

Интеграция поддерживает простой, удобный поток конфигурации через пользовательский интерфейс Home Assistant. Вы можете добавить несколько станций мониторинга, и каждая станция автоматически определит, какие газы она измеряет, и создаст соответствующие сенсоры.

## Поток конфигурации

### Шаг 1: Доступ к настройке интеграции

1. Откройте Home Assistant в веб-браузере
2. Перейдите в **Настройки** → **Устройства и службы**
3. Нажмите кнопку **+ Добавить интеграцию**
4. В поле поиска введите "Moscow Air Quality Monitoring"
5. Нажмите на интеграцию, когда она появится

### Шаг 2: Ввод данных станции

Вы увидите форму конфигурации со следующими полями:

#### URL станции (Обязательно)
- Введите полный URL страницы станции мониторинга с mosecom.mos.ru
- Пример: `https://mosecom.mos.ru/m1-6-moskvorechye-saburovo/`
- URL должен начинаться с `http://` или `https://`
- Интеграция проверит, что URL доступен

#### Имя местоположения (Необязательно)
- Введите пользовательское имя для этого места мониторинга
- Если оставить пустым, имя будет автоматически извлечено из URL
- Пример: Если вы введете "Домашняя станция", сенсоры будут названы `sensor.mosecom_home_station_co`
- Если оставить пустым для URL `https://mosecom.mos.ru/m1-6-moskvorechye-saburovo/`, получится "Moskvorechye Saburovo"

### Шаг 3: Проверка и определение газов

После отправки формы:

1. Интеграция попытается подключиться к станции мониторинга
2. В случае успеха она проанализирует страницу, чтобы определить, какие газы измеряются
3. Вы увидите подтверждение с перечнем обнаруженных газов
4. Пример: "Доступные газы: CO, NO2, CH4, PM10, NO, H2S"

### Шаг 4: Завершение настройки

1. Просмотрите обнаруженные газы
2. Нажмите **Готово**, чтобы завершить настройку
3. Интеграция создаст сенсоры для каждого обнаруженного газа
4. Для каждого газа будет создано два сенсора: один для мг/м³ и один для % ПДК

## Добавление нескольких станций

Вы можете добавить несколько станций мониторинга для наблюдения за разными местами:

### Зачем добавлять несколько станций?

- Мониторинг качества воздуха в разных местах (дом, работа, школа)
- Сравнение качества воздуха в разных районах Москвы
- Некоторые станции измеряют другие газы, чем другие
- Создание комплексной сети мониторинга качества воздуха

### Как добавить несколько станций

1. Следуйте тому же потоку конфигурации для каждой станции
2. Каждая станция должна иметь уникальный URL
3. Каждая станция будет добавлена как отдельный экземпляр интеграции
4. Каждая станция будет иметь свой набор сенсоров в зависимости от измеряемых газов

### Пример: Настройка нескольких станций

**Станция 1: Домашнее местоположение**
- URL: `https://mosecom.mos.ru/m1-6-moskvorechye-saburovo/`
- Имя: "Дом"
- Обнаруженные газы: CO, NO2, CH4, PM10, NO, H2S
- Создает 12 сенсоров

**Станция 2: Рабочее местоположение**
- URL: `https://mosecom.mos.ru/ploshhad-gagarina/`
- Имя: "Работа"
- Обнаруженные газы: C6H5OH, SO2, CH2O, C6H6, O3, NO2, C8H8, C7H8
- Создает 16 сенсоров

**Станция 3: Школьное местоположение**
- URL: `https://mosecom.mos.ru/butovo/`
- Имя: "Школа"
- Обнаруженные газы: CO, NO2, PM10
- Создает 6 сенсоров

Всего: 3 экземпляра интеграции, 34 сенсора

## Поиск URL станций

1. Перейдите на [https://mosecom.mos.ru](https://mosecom.mos.ru)
2. Вы увидите карту Москвы со станциями мониторинга
3. Нажмите на маркер станции, чтобы увидеть её детали
4. Нажмите на название станции или ссылку "Подробнее"
5. Скопируйте URL из адресной строки браузера
6. Используйте этот URL в конфигурации интеграции

Если вы знаете идентификатор станции, вы можете сконструировать URL напрямую:

- Формат: `https://mosecom.mos.ru/<идентификатор-станции>/`
- Пример: `https://mosecom.mos.ru/m1-6-moskvorechye-saburovo/`

## Управление настроенными станциями

### Просмотр всех станций

1. Перейдите в **Настройки** → **Устройства и службы**
2. Найдите "Moscow Air Quality Monitoring" в списке интеграций
3. Вы увидите количество настроенных станций (например, "Moscow Air Quality Monitoring (3)")
4. Нажмите на неё, чтобы увидеть все отдельные записи станций

### Информация о станции

Каждая запись станции показывает:
- Название станции
- Количество сенсоров
- Статус (подключена/отключена)
- Время последнего обновления

### Перенастройка станции

1. Перейдите в **Настройки** → **Устройства и службы**
2. Найдите станцию, которую хотите перенастроить
3. Нажмите на запись станции
4. Нажмите кнопку **Настроить**
5. Обновите URL или имя по необходимости
6. Нажмите **Отправить**, чтобы сохранить изменения

### Удаление станции

1. Перейдите в **Настройки** → **Устройства и службы**
2. Найдите станцию, которую хотите удалить
3. Нажмите на запись станции
4. Нажмите три точки (⋮) в правом верхнем углу
5. Выберите **Удалить**
6. Подтвердите удаление
7. Все сенсоры для этой станции будут удалены

## Обработка ошибок

### Неверный формат URL

**Ошибка**: "Invalid URL format"

**Решение**: 
- Убедитесь, что URL начинается с `http://` или `https://`
- Проверьте опечатки в URL
- Убедитесь, что URL полный (не забудьте завершающий слеш)

### Невозможно подключиться

**Ошибка**: "Failed to connect to the monitoring station"

**Решение**:
- Проверьте правильность URL, открыв его в веб-браузере
- Проверьте подключение к интернету
- Убедитесь, что веб-сайт mosecom.mos.ru доступен
- Попробуйте позже, если веб-сайт временно недоступен

### Уже настроено

**Ошибка**: "This monitoring station is already configured"

**Решение**:
- Каждый URL станции может быть добавлен только один раз
- Если вы хотите перенастроить, используйте опцию "Настроить" в существующей записи
- Если вы хотите удалить и добавить заново, сначала удалите существующую запись

### Неизвестная ошибка

**Ошибка**: "Unknown error occurred"

**Решение**:
- Проверьте логи Home Assistant для получения подробных сообщений об ошибках
- Попробуйте снова через несколько минут
- Убедитесь, что вы используете совместимую версию Home Assistant

## Советы и лучшие практики

### Соглашения об именовании

- Используйте описательные имена для ваших местоположений: "Дом", "Работа", "Школа"
- Избегайте специальных символов в именах
- Более короткие имена создают более короткие ID сенсоров
- Последовательное именование облегчает написание автоматизаций

### Выбор станции

- Выбирайте станции, ближайшие к вашим местам интереса
- Учитывайте, какие газы наиболее важны для вас
- Некоторые станции измеряют больше газов, чем другие
- Проверьте страницу станции на mosecom.mos.ru, чтобы увидеть, что измеряется

### Соображения производительности

- Каждая станция обновляется независимо каждые 5 минут
- Добавление многих станций не значительно повлияет на производительность
- Каждая станция создает 2 сенсора на каждый обнаруженный газ
- Учитывайте свои потребности при добавлении нескольких станций

### Примеры автоматизаций

**Мониторинг высокого уровня CO дома:**
```yaml
automation:
  - alias: "Высокий уровень CO дома"
    trigger:
      - platform: numeric_state
        entity_id: sensor.mosecom_home_co
        above: 5
    action:
      - service: notify.mobile_app_your_phone
        data:
          message: "Высокий уровень CO дома: {{ states('sensor.mosecom_home_co') }} мг/м³"
```

**Сравнение качества воздуха между местами:**
```yaml
sensor:
  - platform: template
    sensors:
      best_air_quality_location:
        friendly_name: "Лучшее место по качеству воздуха"
        value_template: >
          {% if states('sensor.mosecom_home_co_pdk')|float < states('sensor.mosecom_work_co_pdk')|float %}
            Дом
          {% else %}
            Работа
          {% endif %}
```

## Устранение неполадок

### Интеграция не отображается в поиске

1. Убедитесь, что файлы интеграции находятся в правильной директории
2. Перезапустите Home Assistant
3. Очистите кэш браузера
4. Попробуйте обновить страницу интеграций

### Сенсоры не отображаются

1. Проверьте, что интеграция была успешно добавлена
2. Посмотрите описание интеграции, чтобы увидеть, какие газы были обнаружены
3. Если газы не были обнаружены, станция может не передавать данные
4. Проверьте логи Home Assistant на наличие ошибок

### Сенсоры показывают "Неизвестно"

1. Подождите первого обновления данных (до 5 минут)
2. Проверьте доступность веб-сайта станции мониторинга
3. Попробуйте перезагрузить интеграцию
4. Проверьте логи Home Assistant на наличие ошибок подключения

### Неверное имя местоположения

1. Перейдите в конфигурацию интеграции
2. Нажмите "Настроить" на записи станции
3. Обновите имя местоположения
4. Отправьте изменения
5. Примечание: Это не переименует существующие сенсоры, только новые
