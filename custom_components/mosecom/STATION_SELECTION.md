# Функция выбора станции

## Обзор

Интеграция мониторинга качества воздуха Москвы включает интерфейс выбора станции, который позволяет пользователям выбирать станции мониторинга из полного списка.

## Особенности

### Список станций
- **Автоматическая загрузка**: Станции автоматически загружаются с:
  - Обычных станций: https://mosecom.mos.ru/stations/
  - Специальных станций: https://mosecom.mos.ru/special-stations/
- **Подробное отображение**: Каждая станция показывает:
  - Название станции
  - Аббревиатуру района
  - Чистый адрес

## Формат данных станции

Каждая станция в списке содержит:

```python
{
    "name": "М1-6 (Москворечье-Сабурово)",
    "district": "ЮАО",
    "address": "ул. Москворечье, д. 24",
    "url": "https://mosecom.mos.ru/m1-6-moskvorechye-saburovo/"
}
```

## Обработка адресов

Интеграция автоматически очищает адреса следующим образом:

1. **Удаление префиксов Москвы**:
   - "город Москва, "
   - "г. Москва, "
   - "г Москва, "
   - "Москва, "
   - "г. "

2. **Очистка пунктуации**: Удаляет ведущие запятые и точки

3. **Результат**: Чистый адрес, например, "ул. Москворечье, д. 24" вместо "г. Москва, ул. Москворечье, д. 24"

## Пользовательский интерфейс

### Поток конфигурации

1. **Начальная загрузка**: Интеграция загружает все станции с обеих страниц
2. **Выбор станции**: Пользователь видит выпадающий список со всеми доступными станциями
3. **Проверка**: Выбранная станция проверяется перед созданием интеграции

### Формат отображения станции

В выпадающем списке каждая станция отображается как:

```
М1-6 (Москворечье-Сабурово) (ЮАО) - ул. Москворечье, д. 24
```

## Техническая реализация

### Загрузка станций

```python
async def fetch_stations(hass) -> list[dict[str, Any]]:
    """Загрузка всех станций с страниц обычных и специальных станций."""
    stations = []
    
    # Загрузка обычных станций
    regular_stations = await _fetch_page_stations(
        session,
        "https://mosecom.mos.ru/stations/"
    )
    stations.extend(regular_stations)
    
    # Загрузка специальных станций
    special_stations = await _fetch_page_stations(
        session,
        "https://mosecom.mos.ru/special-stations/"
    )
    stations.extend(special_stations)
    
    return stations
```

### Парсинг HTML

HTML страницы станций парсится с использованием регулярных выражений для извлечения:
- Названия станции
- Района (преобразуется из имен CSS классов в короткий формат)
- Адреса (очищается от префиксов Москвы)
- URL

Парсер корректно обрабатывает сложную HTML структуру страниц станций:
- Секции по районам с классом `allstan-item`
- Табличные секции с классом `allstan-item-table`
- Строки с классом `allstan-item-row`
- Данные станции в div'ах `row-title` и `row-address`
- Информация о районе в именах CSS классов (например, `tsao-row`, `sao-row`)

## Схема конфигурации

Поток конфигурации использует следующую схему:

```python
STEP_USER_DATA_SCHEMA = vol.Schema(
    {
        vol.Required(CONF_STATION): vol.In(station_options),
        vol.Optional(CONF_NAME, default=""): str,
    }
)
```

## Обработка ошибок

### Ошибки подключения
- Если список станций не может быть загружен, показывается сообщение об ошибке
- Пользователь может повторить попытку

### Ошибки проверки
- Станция должна быть выбрана из списка
- URL выбранной станции должен быть доступен
- Дублирование станций предотвращается

## Преимущества

1. **Удобство использования**: Нет необходимости вручную искать и копировать URL
2. **Полнота**: Все доступные станции в одном месте
3. **Точность**: Данные станций загружаются непосредственно с официального источника

## Заметки о миграции

### Изменения в версии 3.0.0

- **Упрощенный интерфейс**: Убраны фильтры по районам и специальным станциям
- **Миграция**: Существующие интеграции продолжают работать, но новые должны использовать выбор станции
- **Обратная совместимость**: Старая конфигурация на основе URL по-прежнему поддерживается для существующих записей

### Для существующих пользователей

- Существующие интеграции продолжают работать без изменений
- Для добавления новых станций используйте новый интерфейс выбора станции
- Нет необходимости перенастраивать существующие интеграции

## Устранение неполадок

### Список станций не загружается

1. Проверьте подключение к интернету
2. Убедитесь, что mosecom.mos.ru доступен
3. Проверьте логи Home Assistant на наличие ошибок
4. Попробуйте перезапустить Home Assistant

### Нет станций в списке

1. Проверьте доступность страниц станций
2. Попробуйте перезапустить Home Assistant
3. Парсер успешно извлекает 55 обычных станций и 2 специальных станции

### Неверная информация о станции

1. Данные станций поступают непосредственно с mosecom.mos.ru
2. Сообщите об некорректной информации администраторам сайта
3. Интеграция отображает данные, предоставленные источником
